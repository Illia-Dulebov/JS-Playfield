# Js-Playfield

A hands-on sandbox for learning **JavaScript**, **TypeScript**, and **Node.js** by building, breaking, and experimenting. 

This repository is for educational purposes. It collects small exercises, experiments, and mini-projects created while learning, so the code favors clarity and exploration over production polish.

## Goals

- Build a solid foundation in modern JavaScript (ES6+)
- Learn how TypeScript adds safety and structure on top of JavaScript
- Understand Node.js fundamentals: modules, the event loop, file system, HTTP, and npm
- Keep a public record of progress and practical examples

## What's Inside

| Area | Topics |
|------|--------|
| **JavaScript** | Variables and scope, functions, closures, arrays and objects, async/await, Promises, DOM basics |
| **TypeScript** | Types and interfaces, generics, enums, type narrowing, tsconfig, working with JS libraries |
| **Node.js** | Modules (CommonJS and ESM), file system, HTTP server, npm scripts, environment variables |

## Learning Approach

- Small, focused examples, one concept per file
- Comments explaining the *why*, not just the *what*
- Gradual progression from fundamentals to mini-projects
